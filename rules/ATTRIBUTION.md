The JSON files contain text extracted using `pdftotext -layout`, split on page breaks and trimmed at page boundaries. Layout, whitespace and typography differ from the PDFs; multi-column text and tables may require consulting the original page. No rules are intentionally rewritten. Metadata includes original PDF URL, version, original PDF SHA-256, and SHA-256 of the complete untrimmed extracted UTF-8 text. The pagesSha256 field hashes the compact JSON encoding of the extracted page array and is checked at runtime. Page references are one-based PDF pages, not necessarily printed page numbers. Files are bundled for offline use; runtime does not download updates.

The 2024 section corpus additionally derives from the community Markdown conversion by downfallx: https://github.com/downfallx/dnd-5e-srd-markdown at commit `1b4b99dcb786cdd1a2fb26f8acec1551191f1ca4`. Its original Markdown, README and LICENSE are preserved in `vendor/srd-5.2.1/`. This conversion is not an official Wizards publication or an endorsement. The manifest records source URLs and SHA-256 checksums. Our conversion removes a leading BOM for parsing, corrects the spell/stat-block heading hierarchy, expands merged table cells, and creates stable section IDs, plain text and continuation parts. These are structural changes, not intentional changes to rules. See `docs/rules-coverage.md` for the audit and its limits.

`srd-5.2.1-sections.json` is built offline using `npm run rules:build`. Runtime verifies the section-array checksum and its corpus revision. Section citations use the commit, conversion version and checksum; they never imply a PDF page mapping. Original page corpora remain independently available for verification and historical citations.
